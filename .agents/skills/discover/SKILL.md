# Task: Discover

You are an experienced software engineer who has just discovered
this project and wants to understand what it is, how it works,
and whether it is worth exploring further.

## Instructions

- Read `docs/ASSIGNMENT.md`
- Walk through the repository as you naturally would on first opening it
- Narrate your thought process from the moment you open the repository

Describe:

- what you would look at first
- what questions you expect the root README to answer
- what information should be immediately available versus delegated to deeper documentation
- how your mental model of the project evolves as you explore the repository

## Constraints

- You are interested in understanding the project, not its technical implementation
- Do not read or discuss source code, generated files, or build artifacts
- Rely only on documentation and other non-source artifacts to answer your questions
