# Write Unit Test Suite

Write a complete unit test suite for the given class

## Setup

- Read `TESTING.md`
- Read existing unit test classes to understand the project's testing style
- Read classes in the `testFixtures` module to discover available fixtures
- Only read production classes that are part of the given class's public API

## Steps

- Analyze the given class and identify its behavioral contracts
- Implement one focused unit test for each meaningful behavioral contract
- Stop once all meaningful behavioral contracts have been verified

## Notes

- Use representative test cases and avoid redundant permutations
- Preserve the project's coding, testing, and formatting conventions
- Do not run tests unless specifically requested to do so
